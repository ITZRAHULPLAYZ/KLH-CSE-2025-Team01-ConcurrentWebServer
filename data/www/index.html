OS concepts in this server
pthread_create()

Thread Pool

N worker threads spin up once. No per-request thread overhead.

pthread_mutex_t

Mutex + Condvars

Circular bounded queue shared safely between producer and consumers.

mmap()

Memory-Mapped I/O

Files sent zero-copy directly from the OS page cache.

signal()

POSIX Signals

SIGINT = graceful shutdown. SIGUSR1 = live /proc stats dump.
