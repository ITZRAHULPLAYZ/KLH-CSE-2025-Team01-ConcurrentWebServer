## Abstract

The Concurrent Web Server for University Resource Portal is designed to handle multiple student requests simultaneously during peak hours. The server uses multithreading and concurrency to efficiently serve notices, course materials, exam schedules, and other academic resources. Synchronization techniques are used to safely manage shared resources and prevent conflicts between clients. The system aims to reduce response time, minimize overhead, and improve the performance, scalability, and reliability of the university portal.

## Objectives

- Design and implement a concurrent web server capable of handling multiple simultaneous client connections.
- Serve university resources such as notices, course materials, and exam schedules efficiently.
- Implement a thread pool architecture to manage worker threads and reduce overhead.
- Use synchronization mechanisms such as mutexes and semaphores to prevent race conditions.
- Handle HTTP requests and responses following standard protocol conventions.
- Demonstrate the practical application of operating system concepts including process and thread management.
- Evaluate and compare the performance of the concurrent server against a sequential server baseline.
- Ensure scalability and reliability of the server under peak load conditions.
